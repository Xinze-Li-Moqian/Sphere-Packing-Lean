# Definition — ($E_8$-[[iszlattice|lattice]], Definition 1)

## Statement

> [!definition] ($E_8$-[[iszlattice|lattice]], Definition 1)
> We define the *$E_8$-lattice* (as a subset of $\mathbb{R}^8$) to be
> $$\Lambda_8=\{(x_i)\in\mathbb{Z}^8\cup(\mathbb{Z}+\textstyle\frac12\displaystyle )^8|\;\sum_{i=1}^8x_i\equiv 0\;(\mathrm{mod\;2})\}.$$
